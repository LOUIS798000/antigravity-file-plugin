# Antigravity 文件拖拽辅助工具 (antigravity-file-plugin)

一个轻量的小工具，用于改善 Google Antigravity 桌面端输入框拖拽文件与目录时的使用体验。

---

## 背景与解决的问题

在日常使用 Antigravity 客户端时，经常遇到以下拖拽交互问题：

1. **绝对路径丢失**：在较新版本的 Electron / Chromium 环境中，前端规范限制了直接通过 DOM 读取 `File.path`，导致拖入文件后输入框通常只显示文件名，AI 无法直接获知本地的绝对物理路径，需要用户手动复制完整路径；
2. **部分格式拦截**：客户端原生输入框对拖入文件的扩展名有白名单限制，拖入如 `.docx`、`.xlsx`、压缩包、快捷方式或文件夹等类型时，可能提示格式不支持或无法添加；
3. **残留遮罩浮层**：拖入或快速移出时，有时会在界面残留蓝色的“Drop to add to Agent”虚线框遮挡视线。

本项目通过轻量注入脚本与后台辅助服务，在拖入文件或文件夹时生成带格式标签的小卡片，并在用户发送提问时将本地文件或目录的绝对物理路径附在消息末尾，方便 AI 直接通过文件系统读取和处理。

---

## 主要功能

- **真实绝对路径解析（带盘符）**：全面适配高版本 Electron / Chromium 环境，采用 Windows Explorer 选中项探测、桌面定位、Recent 快捷方式目标解析与工作区关联等多层级高精准算法，百分之百还原带盘符的本地物理绝对路径（如 `D:\...\...`、`C:\...\...`）。
- **全格式文件与目录识别**：支持拖入任意办公文档（Word、Excel、PPT、PDF）、代码文件、压缩包、快捷方式、多媒体文件以及文件夹，在输入框上方生成紧凑彩色标签，支持一键点击移除。
- **自动携带物理路径**：发送消息时自动在内容末尾追加文件或目录的真实绝对本地路径，AI 能够直接基于文件系统精准读写。
- **遮罩自动清理**：在文件放下或移出时自动重置拖放状态，减少残余虚线框卡在界面的情况。
- **轻量本地服务**：单文件后台常驻，占用内存极小，具备单例互斥保护。

## 文件结构

| 文件名 | 说明 |
| :--- | :--- |
| `daemon.js` | 后台常驻守护脚本，自动探测 Antigravity 窗口并通过 CDP 协议注入脚本，提供本地路径辅助查询 |
| `cdp_injector.js` | 核心注入逻辑与浏览器渲染层的拖拽监听 Hook |
| `启动增强服务.bat` | 控制台前台启动脚本（便于查看运行状态与输出） |
| `后台静默启动.vbs` | Windows 脚本，可在后台无黑框静默运行守护进程 |
| `install_autostart.js` | 可选配置脚本，将后台静默启动添加到 Windows 开机启动项 |
| `uninstall_autostart.js` | 可选配置脚本，从 Windows 开机启动项中清理移除 |
| `test_dom.js` | 检测当前 Antigravity 窗口 DOM 状态与 Hook 安装情况 |
| `test_e2e.js` | 端到端渲染测试脚本，模拟各种类型卡片并验证输入框状态 |

## 使用方法

### 1. 环境准备
确保本机已安装 Node.js（推荐 v18 及以上版本）。

### 2. 启动服务
- **日常使用（推荐）**：双击 `后台静默启动.vbs`，将在后台无黑框常驻运行。
- **调试排查**：双击 `启动增强服务.bat`，可在黑框中查看实时注入日志。
- **开机自动运行（可选）**：
  ```bash
  node install_autostart.js
  ```
  如需取消开机自启，运行：
  ```bash
  node uninstall_autostart.js
  ```

### 3. 测试效果
打开 Antigravity 客户端，在任意聊天输入框中拖入桌面或本地的任意文件/文件夹，输入框上方会显示对应文件标签；输入问题并发送后，AI 会自动接收到底部附加的本地绝对路径并直接进行文件处理。

---

## 说明与注意事项

- 本工具纯本地运行，不依赖第三方 npm 库，不收集也不上传任何数据。
- 依赖 Antigravity 客户端自带生成的 DevTools 端口（`DevToolsActivePort`）。
- 仅作为个人日常提高使用效率的辅助脚本。
